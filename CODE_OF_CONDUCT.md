# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, assume good faith, and remember that many people here don't
write code and are learning as they go. Harassment, insults and gatekeeping
aren't welcome.

To report a problem, use GitHub's private vulnerability reporting on this
repository (the **Security** tab), or open an issue that says only "conduct,
please contact me". The maintainer will follow up privately.
