## Notes per source

- **census_gazetteer**: Used to map storm report lat/lon to nearest ZCTA (approximates ZIP code) by centroid distance. Attribution: _ZIP Code Tabulation Area centroids: US Census Bureau Gazetteer Files_
- **coops**:  Attribution: _Source: NOAA CO-OPS_
- **detroit_demolition_permits**: G0 2026-10-24: 16,288 permits; 24 issued last 30 days, 7 last 7 days; 100% have demolition_contractor. PEOPLE-DATA RULE: never request or store owner_name; demolition_contractor is a licensed wrecking business. Attribution: _Data: City of Detroit Open Data Portal_
- **detroit_permits**: G0 2026-10-24: 47,820 permits since 2019-01-02; 570 issued last 30 days, 102 last 7 days. No contractor field. The /pages/terms-of-use URL does not exist on the Hub site (page list has no such slug); the Disclaimer page is the published terms. Fields used: record_id, address, issued_date, permit_type, construction_type, work_description, amt_estimated_contractor_cost, zip_code, neighborhood, council_district. Attribution: _Data: City of Detroit Open Data Portal_
- **detroit_trades_permits**: G0 2026-10-24: 121,606 permits; 1,955 issued last 30 days (Plumbing 1,067, Mechanical 467, Electrical 349, Fire Alarm 26, Elevator 24, Boiler 13, Generator 9); 465 last 7 days; 89% have contact_business_name (contractor business of record). Many plumbing permits are DWSD lead-service-line replacements (utility work, not leads). PEOPLE-DATA RULE: never request or store owner_name or contact_name; use contact_business_name only. Attribution: _Data: City of Detroit Open Data Portal_
- **glerl**: Lane 3 registered this at G0 as the public-domain water-temperature fallback for months when NDBC buoys are pulled (Nov-Apr). Daily lake-average CSVs: https://apps.glerl.noaa.gov/coastwatch/webdata/statistic/csv/all_year_glsea_avg_{s,m,h,e,c}_F.csv ; long-term comparison: avgtemps-{m}_1995-2026_F.csv. Attribution: _Source: NOAA GLERL CoastWatch_
- **glos**: Lane 3 override for G0 inspection only: the public Seagull ERDDAP (https://seagull-erddap.glos.org/erddap/) needs no API key, so key_env is blanked here to let core.fetch make unauthenticated read requests. Core entry still says commercial_ok=unknown; https://glos.org/terms-of-use/ returns 404 (checked 2026-10-24). Lane may NOT ship on GLOS until Nick confirms terms.
- **ndbc**: Great Lakes buoys are seasonal (pulled Nov-Apr). Attribution: _Source: NOAA National Data Buoy Center_
- **nhtsa_odi_flatfiles**: Bulk alternative to the recalls API for a weekly refresh across a whole inventory: one download instead of one call per year/make/model. RCL.txt layout documented in the same folder. Attribution: _Source: NHTSA Office of Defects Investigation_
- **nhtsa_recalls**: No VIN-level open-recall lookup in the public API; that is an NHTSA web tool. Lane 4 must confirm what is possible. Attribution: _Source: NHTSA_
- **nhtsa_vpic**: VINs identify vehicles, not people; still never store owner data. Attribution: _Source: NHTSA vPIC_
- **nhtsa_web**: Registered only so G0 can read NHTSA's own terms and tool descriptions through core.fetch. Not a product data source. Never scrape the VIN lookup tool. Attribution: _Source: NHTSA_
- **noaa_spc_reports**: Files: YYMMDD_rpts_hail.csv, _wind.csv, _torn.csv (preliminary, local-storm-report based). Hail size in hundredths of an inch; wind speed in mph (UNK = damage report with no measured speed). Lane storm-lead raises the daily budget to 2000 for the 24-month backtest; the fetcher cache makes re-runs free. Attribution: _Source: NOAA Storm Prediction Center_
- **noaa_spc_wcm**: Bulk files such as 1955-2024_hail.csv / 1955-2024_wind.csv (final) and per-year files. Used for the backtest where available; daily report files fill the gap. Attribution: _Source: NOAA Storm Prediction Center severe weather database_
- **nws_api**: Requires a descriptive User-Agent (core sets one). Attribution: _Source: National Weather Service_
- **open_meteo**: Non-commercial only on the free tier. Lanes may evaluate it for G0 but cannot ship on it without a paid plan (ask Nick). NWS is the public-domain alternative. Attribution: _Weather data by Open-Meteo.com_
- **openfema**:  Attribution: _Data from OpenFEMA; this product uses FEMA's API but is not endorsed by FEMA._
